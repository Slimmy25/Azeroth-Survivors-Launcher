On a Steam Deck or Linux, the launcher now dresses up its own Steam shortcut so it looks like a real game in the library.

- The shortcut is renamed "Azeroth Survivors" and gets an icon.
- Library artwork is added: cover, wide banner, page background and the game's logo.
- Two screenshots are added to the shortcut's screenshots.
- It all happens by itself on start; the changes appear after Steam restarts (a Deck reboot). Artwork a player set up themselves is never replaced, and the original Steam shortcut file is backed up once.
- The cover, banner, background and screenshots are placeholders for now.

Windows is unchanged.
