# v3.22

The launcher now follows each addon's latest GitHub release automatically, so most addon updates reach players without a launcher update.

- Addons: any catalog entry pointing at a GitHub repository's releases/latest page is updated from that repository's newest release, with its SHA-256 digest checked before installing.
- Addons: 12 catalog entries now use their author's release pages.
- Addons: asset=<start of the ZIP name> in a catalog line picks the ZIP when a release has several.
