# v3.24

This release adds a status log, an error log, and clearer navigation, plus addon version labels and a plain Update All button.

- Launcher: a clickable status line with a 250-message log, a centred status line, and renamed WIKI and BEGINNER GUIDE buttons.
- Launcher: ERROR LOG in Options > Launcher, a more transparent whisper box, and a taller patch notes panel.
- Guide: one favorites button per secondary menu, a Lost? button beside the close X, and no Build Videos entry under Theorycrafting.
- Addons: version labels, separate Survivor UI entries, a plain UPDATE ALL button, and corrected catalog entries and screenshots.
