# Azeroth Survivors Launcher v3.17

## Slim Suite and addon catalog
- Added Azeroth Hub to Download More with the note “A full collection of addons featured in Survivorsforge - INGAME!”.
- Added a movable six-spell row sourced from the game's learned spell data, alongside the independently sourced worn-jewelry row. Both rows can be moved, resized, and switched between horizontal and vertical layouts.
- Encounter health rows can be clicked to request targeting the corresponding visible boss or guardian.
- Standardized the movable tooltip's default size and added resize controls in Slim Suite settings.
- Moved Reset positions into the UI settings category.

## Display and guide
- Included the current display-scaling and guide-layout work from the isolated preview branch.
