# Azeroth Survivors Launcher v3.07

<!-- Add concise, player-facing notes here as changes are made for the next release. -->

- Reworked the Paladin guide into a nested text index with talent and Codex icons. Spell icons in talent rows jump to their spell passages, talent chips on spell rows jump to their descriptions, and Back restores the previous scroll position.

- The breadcrumb favorite heart appears above the bar, centered on the hovered label's visible text. It stays available while moving up to the heart or into that label's dropdown.

- Scroll the mouse wheel over the Paladin contents tree to jump between article sections. The passage follows and the current section stays highlighted; ordinary passage scrolling keeps its usual speed.

- Moved Azeroth Cursor by Maidenhead to Misc in Add-ons → Download More, retaining its existing latest-release download.

- Added Big Cursor by JamieeLee to Misc in Add-ons → Download More, using its latest official ZIP release.

- Added Move UI by JamieeLee to Misc in Add-ons → Download More, using the latest official release ZIP.

- Fixed LocalClock by JamieeLee's existing Misc addon download to match the current official release ZIP naming.

- Improved universal Back navigation: restores Add-ons categories, rollback and inline uninstall views, preserves existing scroll history, and validates destinations before consuming history. Confirmation buttons remain explicit; Back never answers a modal dialog.

- Custom launcher questions and confirmations now overlay the secondary section without rebuilding its contents. Oversized prompt content scrolls inside the available space; native Windows file and folder pickers remain unchanged.
