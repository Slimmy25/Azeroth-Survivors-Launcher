# Azeroth Survivors Launcher v3.12

## Addons and SurvivorsForge
- Download More now includes the requested SurvivorsForge partnership note and links.
- Matching addon releases can show locally cached SurvivorsForge artwork and version-specific review status. The launcher continues to use its own addon catalog and download sources.
- Matching downloads are checked against the provider's SHA-256 before installation.
- README and in-app credits link to SurvivorsForge's website and repository.

## AZS Minor Mods
- Added vertical clock and buff layouts, configurable spacing, screen-edge placement and optional feature hiding.
- Saved UI positions and hidden states persist across `/reload`.
- The replacement Level Up button appears only while an unspent level is available and counts all pending levels.

## Community
- Removed the extra heading above the home page's next-video preview.
