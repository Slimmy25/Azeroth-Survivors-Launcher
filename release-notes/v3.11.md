# Azeroth Survivors Launcher v3.11

## Addons
- Added ASBuilder by Cadoky to Download More > Misc, using the addon from its latest published release.

## AZS Minor Mods
- Added movable and resizable controls for the XP bar, buffs, encounter bars, chat, tooltip, and size menu.
- Added vertical layouts for supported bars, an option to show empty Action Bar 1 slots, and continuous saving of UI positions across `/reload`.
- Improved vertical encounter-bar sizing so the chosen width is honored and the height can be reduced further.

## Game downloads
- Removed the retired developer backup mirror. The launcher tries the two regular download hosts and retains the official game download page as a last resort.
