# v3.38

Slim Suite, Slimjim's movable take on the default UI (formerly AZS Minor Mods), now comes from its own GitHub releases in Download More, and the old AZS Minor Mods copy is retired.

- Download More: Slim Suite installs into its own SlimSuite folder from its latest release. It is still marked Work in Progress, so its button asks you to accept that once; after that it updates like any other addon.
- AZS Minor Mods is gone from the launcher: an AZSMinorMods folder still in AddOns is taken out once, with its old settings, so the two never run together. Slim Suite keeps its own settings.
- Work in Progress addons are no longer left out of updates: once installed, they update automatically (and with UPDATE) like the rest.
- Slim Suite's settings open with /slimsuite (or /slim).
- Survivor UI and Slim Suite still can't be on together, now because both add a full HUD with a damage meter and build list.
