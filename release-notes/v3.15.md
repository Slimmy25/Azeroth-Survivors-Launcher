# Azeroth Survivors Launcher v3.15

## Addon catalog and screenshots
- Renamed the JamieeLee listing to Move UI By Jamie and kept it distinct from AZS MoveAnything by kodfod.
- Added the user-provided addon screenshots as local gallery images. Matching SurvivorsForge screenshots take priority when available; the local images remain a fallback until then.
- Kept Download More cards text-first. Hovering shows a screenshot preview, and clicking opens the larger gallery.
- Added one-word descriptions across the addon catalog. Slim Suite and AZS Handbook use their requested descriptions.

## Slim Suite
- Renamed AZS Minor Mods to Slim Suite and moved its launcher listing to Gameplay.
- Split its settings into “Modifying the User Interface” and “New/Unique, but Minor Features.”
- Added an optional screen grid with 32, 64, 128, and 256 pixel spacing. It is shown during UI editing and the Done control ends the edit session.
- Added an enabled-addon manager. Unchecking an addon changes its enabled state; use “Reload for changes” to apply it.

## Guide and Gear Planner
- Added a Wiki favorite choice: save the current reading location or the top of the page.
- Gear Planner now shows the selected amulet's effects separately from rings and trinkets.
- Added item-model references for the listed classic necklaces.
- Updated the AZS Handbook catalog description.

## Documentation
- Updated the README and replaced its six screenshots with captures from the local display preview. Captures use sample data and simulated display contexts.
