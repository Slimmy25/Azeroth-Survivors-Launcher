# v3.39

The launcher now works with a controller, Dropbox Cloud Save is out of the Steam Deck experiment, and the launcher tells you what changed since you last played. The Wiki marks what recent game patches changed, Stats shows your personal records with solo and co-op apart, and every launcher text is translated.

- Controller support: Start plays, A confirms, B goes back, X saves the current spot to Quick Access, Y jumps to your favorites, the right stick steps through the Wiki's tree, and the left stick moves a glowing blue cursor ball that glows brighter over anything you can click. Xbox controllers and a Steam Deck's controls work, only while the launcher is the active window.
- Dropbox Cloud Save no longer needs STEAM DECK EXPERIMENTAL: sign in under Options > Cloud Save. Google Drive still does.
- What changed since you last played: after a game patch, a launcher update or a Slim Suite update (when it is installed), one window sums up what is new since your last PLAY.
- Patch highlights in the Wiki tree: entries a recent game patch changed are shown in green, with the patch's own lines when you point at them, for 3 game patches.
- Stats: personal records for each class (fastest victory, highest level, most kills, best DPS), solo and co-op apart, and a solo and co-op comparison on the Co-op page.
- When the game does not close normally, the status log says the game saved a crash report in its Diagnostics folder (game patch 0.141.1).
- Closing the launcher while the game runs or Cloud Save is uploading now asks first, and can close it by itself once your progress is saved.
- Google Drive and Dropbox: progress that never reached the cloud is noticed at the next sync and uploaded, instead of being replaced by the cloud's older copy. Switching sync folder, service or account asks on the first sync.
- Addon updates no longer delete files through a linked addon folder, and a failed rollback puts the current version back.
- Spell icons, video thumbnails and GitHub answers are kept between starts, so the launcher downloads less and hits GitHub's limit less often.
- Errors nothing else caught are written to log.txt; unreadable settings are kept aside instead of being overwritten.
- Steam Deck: web links show their address to open on your phone, and PLAY says when Cloud Save is paused.
- Community: SKIP VIDEO is now a small X in the video's top right corner (Skip/Stop).
- Changelog: the game's patch notes 0.143.0 (Hyper Mode) to 0.143.3, word for word. Guide: a Hyper Mode topic and co-op notes.
- Every launcher text is translated into all 26 languages, including messages built from several parts.
- Behind the scenes: Google Drive and Dropbox share one local-copy code path (your sync state is kept), the home screen draws its background from one ready-made picture, the main launcher code is split into smaller files, the item data refresh reads the game's newer layout, Cloud Save's sync logic is tested on every build, and branches named test/<name> get their own test build.
