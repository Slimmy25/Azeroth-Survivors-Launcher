# v3.29

Experimental Steam Deck support, off until you turn it on with the STEAM DECK EXPERIMENTAL button in Options > Launcher (setup's first page offers it on a Steam Deck). With it on, the launcher works as a single "Add a Non-Steam Game" entry: it fills the screen in Game Mode, starts the game itself inside the same Proton session, steps aside while you play and comes back when the game closes to upload your cloud save. With it off, nothing changes.

- One Steam entry is enough: PLAY starts the game from inside the launcher, in the same Proton session.
- In Game Mode the launcher fills the screen without a frame, and its drop-down lists open as a list inside the launcher, because Game Mode shows one window at a time.
- While the game runs the launcher steps aside (hidden in Game Mode, minimized on Windows) and returns when the game closes, before the cloud upload. Options > Launcher can turn this off.
- Options > Launcher can also close the launcher after the game, once the cloud save is uploaded, which takes a Steam Deck straight back to Steam.
- Setup's first page asks "Steam Deck / Handheld, or Windows PC?" and suggests the answer from what the launcher runs on.
- The New Player Handbook has a Steam Deck & Handhelds page: turning it on, adding the launcher to Steam, choosing Proton, Steam + X for the keyboard and Switch Windows.
- For testing: the Status Log's first line says what the launcher detected and whether Steam Deck experimental is on, and starting the launcher with --game-mode tries Game Mode's behaviour on a Windows PC.
