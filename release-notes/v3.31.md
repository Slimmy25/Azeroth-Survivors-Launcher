# v3.31

With STEAM DECK EXPERIMENTAL on, the launcher now comes back the moment the game closes, so Steam's black "Abort game" screen no longer shows while the launcher checks whether the game reopens.

- The launcher returns as soon as the game's process ends, instead of after its 3-second (or, after a game update, up to 45-second) check.
- If the game reopens to update itself, the launcher steps aside again until it closes.
