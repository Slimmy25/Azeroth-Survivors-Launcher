# v3.36

Work-in-progress addons in Download More can now be installed, after you agree to a warning that they are not ready for release.

- Press an addon's Work in Progress button. The launcher explains that it may be unfinished, change a lot or stop working between versions, can cause errors in the game, and is not updated automatically.
- Choose YES to install it like any other addon; NO leaves it uninstalled. UNINSTALL removes it as usual.
