# v3.30

With STEAM DECK EXPERIMENTAL on, the launcher now starts the game with WGPU_BACKEND=vulkan when it runs under Proton, so the Steam entry no longer needs "WGPU_BACKEND=vulkan %command%" in its launch options.

- Only under Proton or Wine with Steam Deck experimental on; Windows PCs are never affected.
- If WGPU_BACKEND is already set in the Steam entry's launch options, that value is kept.
- The Status Log says whether the launcher added it or kept yours.
