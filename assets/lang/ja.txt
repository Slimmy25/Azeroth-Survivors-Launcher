Separated from Profile 2: this profile keeps its own copy of the game's preferences, so a heavy UI addon can change them without leaving them set in a way that makes the next UI addon look wrong.
= プロファイル2とは別：このプロファイルはゲーム設定の独自のコピーを持つので、大型UIアドオンが設定を変えても、次のUIアドオンの見た目がおかしくなることはありません。
Separated from Profile 1: this profile keeps its own copy of the game's preferences, so a heavy UI addon can change them without leaving them set in a way that makes the next UI addon look wrong.
= プロファイル1とは別：このプロファイルはゲーム設定の独自のコピーを持つので、大型UIアドオンが設定を変えても、次のUIアドオンの見た目がおかしくなることはありません。
No profile doesn't do what Profile 1 and Profile 2 do: it keeps no copy of its own. It only switches addons on and off, and the game's preferences stay as the game and your addons leave them, shared by everything. If you don't want the game's preferences changed, use this setting.
= 「プロファイルなし」はプロファイル1と2のような働きはしません。独自のコピーを持たず、アドオンのオン・オフだけを切り替え、ゲーム設定はゲームとアドオンが残したまま共通で使われます。ゲーム設定を変更したくない場合は、これを使ってください。

Profile 1 keeps a full copy of itself in its own isolated space, apart from Profile 2 and No profile: which addons are on, where the interface sits and every addon's settings. A heavy UI addon can change things here without touching the others, and when you come back to Profile 1 it is exactly the way you left it.
= プロファイル1は、プロファイル2や「プロファイルなし」とは別の独立した場所に、自分の完全なコピーを持ちます。オンにするアドオン、インターフェースの配置、各アドオンの設定です。大型UIアドオンがここで何かを変えても他には影響せず、プロファイル1に戻ると離れたときのままです。
Profile 2 keeps a full copy of itself in its own isolated space, apart from Profile 1 and No profile: which addons are on, where the interface sits and every addon's settings. A heavy UI addon can change things here without touching the others, and when you come back to Profile 2 it is exactly the way you left it.
= プロファイル2は、プロファイル1や「プロファイルなし」とは別の独立した場所に、自分の完全なコピーを持ちます。オンにするアドオン、インターフェースの配置、各アドオンの設定です。大型UIアドオンがここで何かを変えても他には影響せず、プロファイル2に戻ると離れたときのままです。
No profile is the game as it normally is, kept as a full copy in its own isolated space: which addons are on, where the interface sits and every addon's settings. While you use it the launcher changes nothing, and when you come back to it from a profile it is exactly the way you left it. If you don't want the game's preferences changed, use this setting.
= 「プロファイルなし」は普段どおりのゲームを、独立した場所に完全なコピーとして保管します。オンにするアドオン、インターフェースの配置、各アドオンの設定です。使っている間ランチャーは何も変えず、プロファイルから戻ると離れたときのままです。ゲーム設定を変更したくない場合は、これを使ってください。
