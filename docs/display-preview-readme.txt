Azeroth Survivors Launcher — Display Preview (isolated local build)

This is a private test build for the display-scaling overhaul. It is not a public release.

To try it, extract this folder to a new location and run:
  Azeroth Survivors Launcher - Display Preview.exe

It has its own “Display Preview Data” folder beside the EXE, its own Windows instance/taskbar identity, and will not replace the normal launcher or use its saved preferences. It will not check for or install public launcher updates, and it does not automatically update addons. The normal public main branch and release are unchanged.

This is still a functional launcher. If you choose a game/AddOns/settings folder, related launcher actions can affect that selected folder. For a visual-only check, leave the folder choices alone and close the preview when finished. Its first-run marker and preview preferences are confined to this extracted folder.

The included screenshots and validation results come from off-screen rendering with actual WinForms controls. Resolution/DPI combinations other than this PC’s current 144-DPI context are simulated; physical mixed-monitor behavior still needs a test on a two-monitor Windows setup.

The SHA-256 file beside the EXE is the checksum for this build.
